# Support

This is the default support policy for EdgeFirstAI repositories. A repository
that ships its own `SUPPORT.md` supersedes it.

## Where to ask

| You want to | Go to |
|-------------|-------|
| Report a bug, or ask about a project | **Issues** on that repository |
| Propose a change | A pull request — see [CONTRIBUTING.md](https://github.com/EdgeFirstAI/.github/blob/main/CONTRIBUTING.md) |
| Report a vulnerability | **Security** tab → *Report a vulnerability*, or `support@au-zone.com`. Never a public issue — see [SECURITY.md](https://github.com/EdgeFirstAI/.github/blob/main/SECURITY.md) |
| Ask something commercial: licensing, support agreements, professional services | `support@au-zone.com` |
| Raise a conduct concern | Security tab private report, or `support@au-zone.com` — see [CODE_OF_CONDUCT.md](https://github.com/EdgeFirstAI/.github/blob/main/CODE_OF_CONDUCT.md) |

## Before opening an issue

Say what you expected, what happened instead, and how to reproduce it. Include
the version you are on and the platform — most EdgeFirst software targets
embedded Linux on specific hardware, and "which board" is usually the first
question anyway.

If it reproduces only on hardware, say which device, which BSP or image, and
which driver versions.

## What to expect

These are open-source projects maintained by
[Au-Zone Technologies](https://au-zone.com). Issues are read, and answered as
maintainer time allows; there is no response-time commitment on the public
trackers. Security reports are the exception and have the timelines in
[SECURITY.md](https://github.com/EdgeFirstAI/.github/blob/main/SECURITY.md).

Commercial support, including guaranteed response times, is available through
Au-Zone — `support@au-zone.com`.
